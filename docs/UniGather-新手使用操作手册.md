# UniGather 材料收集系统

## 新手使用操作手册

版本：0.0.4（Windows 单机版）  
适用对象：总部材料收集人员、综合管理人员、行政人员

---

## 一、先理解软件能做什么

UniGather 有两项相互独立的核心工作：

1. **收集任务**：从邮箱收取各单位反馈邮件，按照单位和关键词判断谁已经反馈、谁还没有反馈，并把附件归档到本机。
2. **邮件发送**：扫描本机某个材料文件夹，按照通讯录把文件匹配到单位，再给每个单位单独发送邮件。

简单理解：

- 收集任务是“收进来、判断反馈情况”。
- 邮件发送是“从本机材料中找出来、分别发出去”。

两项功能都使用同一份通讯录和同一份邮箱配置，但邮件发送不需要关联某个收集任务。

---

## 二、第一次使用前要做的准备

第一次打开软件，建议按下面顺序操作：

1. 配置邮箱收件和发信服务器。
2. 导入通讯录。
3. 设置材料保存目录。
4. 创建一个收集任务，先用少量单位测试。
5. 再使用邮件发送工作台进行目录扫描和测试发送。

建议先准备好以下信息：

- 收件服务器：IMAP 或 POP3 地址、端口、加密方式。
- 发信服务器：SMTP 地址、端口、SSL/TLS 或 STARTTLS。
- 邮箱账号和密码。
- 如果公司网络需要代理：代理类型、地址、端口、账号和密码。
- 通讯录 Excel/CSV 文件。
- 收取附件要保存到的本机目录。

---

## 三、邮箱配置：先把“收”和“发”都配置好

### 3.1 打开邮箱配置

点击左侧导航栏的 **“邮箱配置”**。

邮箱配置分为三部分：

- 收件连接
- 发信连接
- 代理设置

### 3.2 填写收件连接

在“收件连接”中填写：

| 字段 | 怎么填写 |
|---|---|
| 配置名称 | 例如“总部邮箱”或“材料收件箱” |
| 收件协议 | 通常选择 IMAP；如果公司邮箱只支持 POP3，再选择 POP3 |
| 收件服务器 | 例如 `imap.example.com` |
| 端口 | IMAP + SSL/TLS 常见为 993；POP3 + SSL/TLS 常见为 995 |
| 收件账号 | 完整邮箱地址，例如 `zhangsan@example.com` |
| 密码 | 邮箱登录密码或邮箱授权码 |
| 加密方式 | 按邮箱服务商要求选择 SSL/TLS 或 STARTTLS |

密码只用于连接邮箱，不会显示在页面，也不应写入普通配置文件。

### 3.3 填写发信连接

在“发信连接”中填写：

| 字段 | 怎么填写 |
|---|---|
| SMTP 服务器 | 例如 `smtp.example.com` |
| SMTP 端口 | SSL/TLS 常见为 465；STARTTLS 常见为 587 |
| 加密方式 | 选择 SSL/TLS 或 STARTTLS |
| 发件人名称 | 可填写“总部材料工作组”，也可以留空 |

发信账号默认复用上面的收件账号，不需要在“邮件发送”页面再次填写服务器。

### 3.4 配置代理

如果公司网络必须经过代理才能访问邮箱：

1. 打开“使用代理”开关。
2. 选择 HTTP 或 SOCKS5。
3. 填写代理地址和端口。
4. 如果代理需要认证，再填写代理账号和代理密码。
5. 点击“测试连接”。

收件和发信共用这一份代理配置。

### 3.5 测试并保存

填写完成后按以下顺序操作：

1. 点击 **“测试连接”**。
2. 等待提示“连接测试通过”或查看错误原因。
3. 点击 **“保存邮箱配置”**。
4. 关闭并重新打开软件，确认服务器、账号、代理信息仍然存在。

如果提示密码未保存：

- 重新填写密码后保存；
- 确认账号与邮箱地址完全一致；
- 如果邮箱启用了二次验证，使用邮箱服务商生成的授权码，而不是网页登录密码。

## 四、通讯录：导入单位、联系人和邮箱

### 4.1 通讯录字段说明

点击左侧 **“通讯录”**。当前通讯录支持：

| 字段 | 用途 |
|---|---|
| 单位名称 | 任务匹配和发送匹配的主要依据 |
| 联系人 | 方便人工识别和联系 |
| 邮箱 | 收件匹配来源，也用于发送 To 收件人 |
| 电话 | 仅作为联系人信息保存 |
| 单位别名 | 用于匹配文件名中的简称、旧名称或地区简称 |

一个单位可以有多个联系人和多个邮箱。发送时，同一单位的多个有效邮箱会合并到同一封邮件的 To 中。

### 4.2 下载模板

在通讯录页面点击 **“下载模板”**，模板列为：

```text
单位名称,联系人,邮箱,电话,单位别名
```

单位别名有多个时，可以用分号分隔，例如：

```text
北方分公司,张三,zhangsan@example.com,010-12345678,北方公司;北京分公司
```

### 4.3 导入 Excel 或 CSV

1. 准备 `.xlsx`、`.xls` 或 `.csv` 文件。
2. 点击 **“导入 Excel”**。
3. 选择文件。
4. 等待导入结果提示。
5. 导入成功后，页面会显示通讯录列表。

旧版模板也可以继续使用：

- `单位名称,邮箱`
- `单位名称,姓名,邮箱`
- `单位,姓名,邮箱`

### 4.4 导入后修改单行

导入完成后，每一行都可以直接修改：

1. 找到需要修改的单位。
2. 直接在单位名称、联系人、邮箱、电话或别名输入框中修改。
3. 点击该行右侧的 **“保存”**。

修改邮箱时要注意：

- 多个邮箱可以用分号或逗号分隔；
- 不要把姓名、备注文字写进邮箱栏；
- 邮箱地址必须完整，例如 `unit@example.com`。

## 五、材料归档：设置附件保存位置

点击左侧 **“材料归档”**。

1. 在“材料保存路径”中点击 **“选择目录”**。
2. 选择一个有写入权限的本机文件夹，例如：

```text
D:\UniGather\Materials
```

3. 点击 **“保存路径”**。
4. 以后收集任务收到的附件会保存到这个目录。

建议不要选择桌面、系统目录或需要管理员权限的目录。归档文件同名时不会覆盖原文件，系统会追加时间或序号。

## 六、重点功能一：创建并运行收集任务

### 6.1 创建任务

点击左侧 **“收集任务”**，再点击右上角 **“新建任务”**。

任务窗口分为基础信息、单位范围、时间与规则几部分，所有内容在一个窗口中完成。

### 6.2 填写任务名称

例如：

```text
2026年第三季度经营材料收集
```

任务名称只用于识别，不直接决定邮件匹配结果。建议写清楚“年份 + 期次 + 材料名称”。

### 6.3 填写主题关键词

在“主题关键词”中填写邮件主题中可能出现的关键词，多个关键词用逗号分隔，例如：

```text
季度材料,经营分析,三季度报表
```

关键词越准确，误匹配越少。不要只填写“材料”这种过于宽泛的词。

主题关键词下方的提示文字只是说明，不是输入框；如果窗口较小，请滚动任务窗口内容区查看完整提示。

### 6.4 选择本任务涉及的单位

点击“选择单位”区域：

1. 可以在搜索框输入单位名称、联系人或邮箱。
2. 点击 **“全选”**，选择全部通讯录单位。
3. 也可以逐行勾选本次实际涉及的单位。
4. 不需要的单位不要勾选。

至少选择一家单位。任务只会把邮件匹配到所选单位，不会影响通讯录中的其他单位。

### 6.5 设置收件时间范围

时间范围决定任务查收哪些邮件：

- **查收起始时间**：默认当前时间；如果要补查历史邮件，可以改成过去的时间。
- **截止时间**：任务到该时间后不再自动收件；留空或未来时间会按实际时间处理。

也可以使用快捷按钮：

- 最近 7 天
- 今天
- 现在

例如，要补查 8 月 1 日到 8 月 10 日的邮件：

```text
查收起始时间：2026-08-01 00:00
截止时间：2026-08-10 23:59
```

### 6.6 设置轮询间隔

轮询间隔表示软件自动检查邮箱的频率：

- 每 30 分钟
- 每 1 小时
- 每 2 小时

它不是“只收取最近 30 分钟的邮件”，而是“每隔多久再次检查一次”。每次检查仍然按照任务设置的起始时间和截止时间处理邮件。

自动收件只在软件运行或最小化到托盘期间继续。彻底退出软件后不会继续收件。

### 6.7 AI 辅助匹配开关

启用 AI 后，系统只会发送邮件主题、正文和附件名称用于辅助判断，不上传附件文件内容。AI 建议不能替代人工确认，低置信度或多候选结果仍然需要人工处理。

如果公司不允许使用外部 AI，可以关闭此开关，使用发件人邮箱、主题和正文关键词进行确定性匹配。

### 6.8 保存并查看任务进展

点击 **“保存任务”** 后，任务会立即出现在任务列表。

任务列表通常会显示：

- 任务名称
- 涉及单位数量
- 截止时间
- 轮询间隔
- 已反馈百分比
- 任务状态

点击任务行可以查看任务详情，包括：

- 已反馈/总单位数
- 查收起始时间
- 截止时间
- 上次收件时间
- 下次自动收件时间
- 主题关键词
- 材料保存目录

### 6.9 立即刷新历史邮件

新建任务后，不需要等待 30 分钟：

1. 点击任务行打开任务详情。
2. 点击 **“立即刷新”**。
3. 软件会立即按照任务的查收起始时间到截止时间收取邮件。
4. 邮件会逐封处理，页面会显示当前进度。

如果起始时间设置为过去日期，就可以用这个功能补查历史邮件。

### 6.10 判断哪些单位未反馈

任务进度会把单位分为不同状态：

- 已反馈/已确认
- 待人工确认
- 临期
- 逾期
- 未反馈

收到邮件不一定代表自动确认成功。如果发件人邮箱无法对应通讯录、主题不符合关键词，或同一封邮件同时命中多个单位，就需要人工确认。

## 七、收件箱：查看实际收到的邮件

点击左侧 **“收件箱”**，可以查看已经同步到本机的邮件。

### 7.1 立即收件

1. 在“收件起始时间”选择要收取的起始时间。
2. 点击 **“立即收件”**。
3. 页面会显示收件进度。
4. 收到一封后，邮件列表会逐步出现邮件。

默认收取近 7 天邮件；如果填写了时间，则按填写的时间开始收取。

### 7.2 搜索和查看邮件

左侧邮件列表支持搜索：

- 发件人
- 邮件主题
- 邮件正文

点击左侧某封邮件，右侧会显示：

- 发件人
- 收件人
- 抄送人
- 主题
- 正文
- 附件列表

附件如果是扫描件或图片，可能只归档而不提取文本，这是正常提示。

## 八、重点功能二：独立邮件发送工作台

邮件发送不依赖收集任务。它适用于“总部已经准备好各单位材料，现在要按单位分别发出去”的场景。

### 8.1 进入邮件发送

点击左侧 **“邮件发送”**。

页面按 5 个区域排列：

1. 材料来源
2. 自动匹配
3. 邮件内容
4. 检查与发送
5. 发送记录

### 8.2 选择材料目录

在“材料来源”区域：

1. 点击 **“选择目录”**。
2. 选择存放待发送材料的文件夹。
3. 如果材料在子文件夹中，保持勾选 **“扫描子目录”**。
4. 点击 **“开始扫描”**。

系统会扫描常见文件格式，例如 PDF、Word、Excel、CSV、TXT 和图片文件，并显示发现的文件数量。

建议一个批次只放同一项工作的材料，避免把无关文件一起扫描。

### 8.3 查看自动匹配结果

系统会根据文件名匹配通讯录：

1. 先匹配单位名称。
2. 再匹配单位别名。
3. 去除空格、下划线、括号等符号后进行本地模糊匹配。
4. 低置信度项目进入待确认，不会直接发送。

匹配列表中会显示：

- 文件名
- 匹配方式
- 置信度
- 建议单位
- 收件邮箱
- 当前状态

### 8.4 人工改派或处理未匹配文件

如果状态是“待确认”或“未匹配”：

1. 点击该行的单位下拉框。
2. 选择正确单位。
3. 确认该单位显示了有效邮箱。
4. 如果文件不应该发送，可以将其标记为忽略。

正式发送前，所有未匹配、待确认、无有效邮箱的项目都必须处理完。

### 8.5 填写邮件内容

在“邮件内容”区域填写：

#### 邮件主题

例如：

```text
请查收2026年第三季度经营材料 - {单位名称}
```

系统发送给不同单位时，会自动把 `{单位名称}` 替换成实际单位名称。

#### 邮件正文

例如：

```text
您好，{单位名称}：

请查收本次材料。如有问题，请及时与总部材料工作组联系。

谢谢。
```

#### 批次级抄送

多个抄送邮箱用逗号、分号或空格分隔，例如：

```text
manager@example.com; archive@example.com
```

这些地址会统一放到每个单位邮件的 CC 中。

#### 测试收件邮箱

填写自己的邮箱或专门的测试邮箱。点击“发送测试”时，系统只会向测试邮箱发送一封测试邮件，不会正式发送给所有单位。

### 8.6 查看按单位拆分的预览

右侧“邮件预览”会显示：

- 每个单位将收到几封邮件（正常为每单位 1 封）
- To 收件人
- 附件数量

同一单位的多个附件会合并到同一封邮件中；同一单位的多个有效邮箱会合并到 To。

### 8.7 启动检查

点击 **“启动检查”**，系统会检查：

- 是否已扫描材料目录；
- 主题和正文是否为空；
- 是否还有待确认或未匹配文件；
- 单位是否有有效邮箱；
- 是否存在附件被多个单位使用的风险。

有错误时必须先处理错误。警告信息需要认真确认后再继续。

### 8.8 发送测试

1. 确认测试收件邮箱正确。
2. 点击 **“发送测试”**。
3. 等待页面显示发送进度和结果。
4. 在测试邮箱中检查：发件人、主题、正文、抄送和附件。

只有测试成功后，才建议正式发送。

### 8.9 正式发送

正式发送前请再检查一次单位和附件：

1. 点击 **“正式发送”**。
2. 在确认框中准确输入：

```text
确认发送
```

3. 点击确认。
4. 页面按单位显示发送进度。

正式发送后，每个单位都会记录成功或失败状态。成功项目不会因为重试失败项而重复发送。

### 8.10 失败项重试

在“发送记录”区域找到对应批次：

1. 查看失败数量和失败原因。
2. 确认邮箱配置已经修正，例如密码、代理或 SMTP 端口。
3. 点击 **“重试失败项”**。
4. 系统只重新发送失败单位，已成功单位不会重复发送。

## 九、常见问题排查

### 9.1 点击立即收件后没有邮件

按顺序检查：

1. 邮箱配置是否点击过“测试连接”。
2. 收件起始时间是否设置得太晚。
3. 账号密码是否为授权码。
4. 代理是否打开并填写正确。
5. 邮箱服务器是否允许 IMAP/POP3。
6. 收件箱是否确实存在目标时间范围内的邮件。

### 9.2 提示 SMTP 服务器未配置

进入“邮箱配置”，填写“发信连接”中的 SMTP 服务器、端口和加密方式，然后保存。邮件发送页面不再单独填写 SMTP。

### 9.3 文件没有匹配到单位

检查：

- 文件名是否包含单位名称或单位别名；
- 通讯录中是否有该单位；
- 单位别名是否填写正确；
- 文件名中是否包含大量无法识别的缩写。

可以在匹配列表中人工选择单位。

### 9.4 单位有多个邮箱，邮件会发给谁

同一单位的多个有效邮箱会合并到同一封邮件的 To 中，不会拆成多封重复邮件。

### 9.5 关闭软件后还会自动收件吗

彻底退出后不会。最小化到托盘时，软件仍会按任务轮询间隔运行。

### 9.6 为什么扫描件只显示“仅归档”

图片或扫描 PDF 没有可直接提取的文字时，系统会保存原附件，但不会伪造提取结果。后续如需识别扫描件，需要额外接入 OCR。

### 9.7 邮件发送是否会把附件上传到 AI

不会。AI 辅助只允许使用主题、正文、附件名称、单位名称和必要的通讯录摘要；正式发送仍需要人工确认。

## 十、日常工作建议

### 每次收集工作的建议顺序

1. 检查邮箱配置和代理是否仍有效。
2. 更新通讯录，确认新增单位和邮箱。
3. 设置材料保存目录。
4. 创建任务并只选择本次涉及的单位。
5. 设置正确的查收起始时间和截止时间。
6. 点击任务详情中的“立即刷新”做首次收取。
7. 查看待确认和未反馈单位。
8. 临近截止时间再次立即刷新。
9. 导出材料清单或未反馈名单。

### 每次发送工作的建议顺序

1. 将本批次材料整理到一个独立目录。
2. 确认通讯录中的单位名称、别名和邮箱正确。
3. 扫描目录并处理全部待确认文件。
4. 检查每个单位的附件和收件人预览。
5. 发送测试邮件。
6. 在真实邮箱中检查测试结果。
7. 输入“确认发送”进行正式发送。
8. 保存或记录失败项，必要时只重试失败项。

## 十一、安全注意事项

- 不要把邮箱密码写在 Excel、任务名称或邮件正文中。
- 不要把无关文件放入待发送目录。
- 正式发送前必须先测试，避免误发大量邮件。
- 检查 To 和 CC，避免把内部地址误放入所有单位的收件人中。
- 定期备份通讯录和材料归档目录。
- 如果使用代理或 AI 服务，请遵守公司网络和数据安全规定。
