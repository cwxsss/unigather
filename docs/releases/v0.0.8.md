# UniGather v0.0.8

发布日期：2026-09-18

## 修复

- **邮箱密码持久化**：修复邮箱密码无法保存、每次打开软件都需要重新填写的问题。根因是密码托管组件缺少 Windows 平台后端，设置密码时只在内存中生效；现改用 Windows 凭据管理器保存，重启后自动读取。若此前保存过密码，升级后请重新填写并保存一次。
- **同一单位最新反馈附件**：同一单位存在多次反馈时，以邮件接收时间最新的已确认反馈为当前有效反馈；发送材料时仅使用该次反馈的附件，避免重复发送历史附件。
- **正文内嵌图片**：邮件签名、Logo 等 `inline`/CID 内嵌图片不再被识别为普通附件；明确标记为 `attachment` 的真实附件仍正常归档。
