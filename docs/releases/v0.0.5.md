# UniGather v0.0.5

发布日期：2026-08-13

## 任务中心与反馈管理

- 收集任务支持软删除、恢复、停止、重新运行、重命名和编辑，避免误删任务后无法找回。
- 当任务范围内全部单位已确认反馈时，系统自动将任务标记为已完成。
- 收集任务页面改为紧凑任务摘要与运行中任务卡片；反馈状态、待反馈单位、待确认邮件和未匹配邮件可按任务下钻查看。
- 反馈情况和匹配结果支持页码翻页，不再依赖长列表滚动；点击“查看邮件”可直接跳转至收件箱对应邮件。
- 任务工作台聚焦任务规则、时间范围与涉及单位，不再重复显示匹配邮件列表。

## 收件与材料归档

- 收件箱采用固定双栏布局：邮件列表与邮件正文独立滚动，减少横向溢出和阅读干扰。
- 收件起始时间支持选择与直接输入，移除了无实际作用的刷新按钮。
- 收到的邮件可按发件人邮箱、显示名称、单位名称和单位别名识别单位；未匹配原因会保留展示。
- 已匹配附件归档到“已匹配”目录，未匹配附件归档到“未匹配”目录；无附件邮件会将正文生成 Word 文档归档。

## 界面与可用性

- 左侧导航固定，通讯录调整到仪表盘下方、收件箱调整到通讯录下方。
- 新建/编辑任务中的单位选择器改为更易阅读的紧凑行：单位名称与联系人摘要字号增大，行高固定 40px，单位之间不再出现额外空白。
- 待反馈单位联系人和邮箱支持悬停查看完整内容，并可从待反馈模块直接导出名单。

## 验证

- 前端核心逻辑测试：50 项通过。
- Vite 生产构建通过。
- Windows Tauri release 构建通过，已生成 NSIS 与 MSI 安装包。

- `UniGather_0.0.5_x64-setup.exe`：NSIS 安装包，适合普通用户。
- `UniGather_0.0.5_x64_zh-CN.msi`：MSI 安装包，适合企业软件分发。
