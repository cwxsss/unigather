# 邮箱实际收件设计

## 范围

收件箱“立即收件”使用用户配置的 IMAP/POP3 账号连接收件服务器。界面新增可编辑“收件起始时间”，默认当前时间前 7 天；同步范围为起始时间至执行时刻。

## 数据流

前端将邮箱连接配置、当前输入的密码、任务编号和起始时间传给 Tauri `sync_start`。Rust 在后台线程中根据协议建立 TLS 连接，按 IMAP UID/POP3 邮件逐封读取，解析邮件头、正文和附件元数据，按邮箱账号、外部邮件标识和内容摘要去重后写入 SQLite。前端通过 `sync_status` 轮询进度，并通过 `mail_list` 增量刷新已保存邮件。

## 失败与安全

连接、认证、TLS、解析和单封邮件失败均返回可读错误；密码只在本次命令调用中传输，不写入 SQLite 或日志。代理连接层支持 HTTP CONNECT 和 SOCKS5/SOCKS5H，并支持代理账号密码。

## 验收

- 默认起始时间为近 7 天，修改后按修改值查询。
- IMAP/POP3 连接错误可见，成功邮件进入收件箱。
- 重复同步不重复插入。
- 收件箱显示发件人、收件人、抄送、主题、正文、时间和附件；收件过程中逐封显示进度。
- 已归档附件可在邮件详情中点击，用系统关联程序打开。
