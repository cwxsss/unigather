# 任务单位范围选择设计

## 目标

新建或编辑收集任务时，用户可以选择本次任务涉及的单位范围，避免所有任务默认使用同一份单位清单。

## 交互

- 任务弹窗增加“选择单位”区域，显示单位名称、联系人和邮箱数量。
- 支持单位搜索、全选、清空和逐项复选；显示“已选 / 总数”。
- 新任务默认不选单位，至少选择一家后才能保存。
- 编辑任务时回显已有单位选择；保存后同步更新关联。
- 没有导入单位时显示引导信息，保存任务时提示先导入单位。

## 数据流

- 后端增加 `company_list` 命令，返回稳定单位 ID、名称、联系人和邮箱数量。
- `TaskSummary` 增加 `company_ids`，用于编辑任务回显。
- 创建任务写入所选 `task_companies`；更新任务在事务中替换该任务的关联单位。
- 浏览器预览模式使用本地单位数据和稳定的本地 ID，桌面模式使用 SQLite 返回的真实 ID。

## 验收

- 全选、清空、单选、多选和搜索结果选择状态正确。
- 新建任务提交的单位 ID 与页面选择一致。
- 编辑任务打开时选择状态与数据库一致，修改后关联数量正确。
- 不选择单位、单位清单为空时有明确错误提示。
