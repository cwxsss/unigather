# 材料版本管理实现计划

目标：同一任务、同一单位按原始附件名选择最新已确认版本；补充附件保留，历史可追溯。

- 在 `src-tauri/src/material_versions.rs` 集中查询当前/历史版本，按邮件接收时间排序，保留原始文件并生成当前材料和历史版本副本。
- 在 `db.rs` 添加副本路径索引，兼容已有数据库；在 `lib.rs` 接入同步、人工确认、详情、发送和导出，现有材料首次访问时生成版本目录。
- 在 `models.rs` 与 `src/main.js` 展示当前/历史标签、反馈次数、最近反馈时间、附件来源时间和历史打开入口；清单只导出当前材料。
- 在收集任务表单添加单独的附件存放目录和目录选择按钮，新建默认全局目录，编辑保留任务路径；修改目录后材料复制到新位置，原件保留。
- 新增用户随后要求的单位分组：以通讯录单位 ID 持久化分组，可从当前勾选或邮箱列表创建、编辑，一键选择整组，支持部分选中和失效成员提示；保存任务仍记录最终单位 ID，不动态绑定分组。
- 回归验证同名替换、不同名补充、无附件邮件、乱序收件、重复刷新和历史/当前文件内容；运行相关 Rust/前端检查与生产构建。

不在此任务中自动提升版本、提交或发布新 Release。
